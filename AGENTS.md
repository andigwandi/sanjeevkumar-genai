# Custom Project Instructions & Versioning Policy

## Versioning Scheme
- Format: `1.{minor}.{YYYYMMDD}`
- Current starting version: `1.2.20260827`
- **Mandatory Rule**: With every new release, publish, git sync, or feature update, increment the minor version number (e.g. `1.2.{YYYYMMDD}` -> `1.3.{YYYYMMDD}` -> `1.4.{YYYYMMDD}`) and update the timestamp date in `constants.ts` (`APP_VERSION`).
- The version must always be displayed clearly in the application footer.
